Directory Monitoring Script (Bash)

A lightweight and real-time directory monitoring tool built using Bash and inotifywait.
This script watches a specified folder and logs all CREATE, MODIFY, and DELETE events into a log file.

 Features

 Monitors any directory in real time

 Logs all file changes (create/modify/delete)

 Works recursively (subfolders included)

 Lightweight — no external tools except inotifywait

 Easy to test and run

 Requirements

Make sure inotify-tools is installed:

sudo apt install inotify-tools

 Project Structure
dir_monitor/
│
├── dir_monitor.sh        # Main script
└── dir_changes.log       # Log file generated by script

 Usage

Run the script with:

./dir_monitor.sh <directory_to_monitor> <log_file>

Example:
./dir_monitor.sh ~/testmonitor dir_changes.log


You should see:

Monitoring started for directory: /home/youruser/testmonitor
Watches established.

 How It Works

The script uses:

 inotifywait

A Linux utility that listens for file system events.

Events Captured:

CREATE

MODIFY

DELETE

Every event is logged in the following format:

YYYY-MM-DD HH:MM:SS | EVENT | /path/to/file

 Testing the Script

Open another terminal and try:

Create a file:
touch ~/testmonitor/test1.txt

Modify the file:
echo "hello" >> ~/testmonitor/test1.txt

Delete the file:
rm ~/testmonitor/test1.txt


You will see all events appear in real-time.

 Viewing Logs

After stopping the script (CTRL + C):

cat dir_changes.log

 Troubleshooting
 Error: /usr/bin/env: ‘bash\r’: No such file or directory

Your script has Windows line endings.

Fix using:

sed -i 's/\r$//' dir_monitor.sh


Or:

sudo apt install dos2unix
dos2unix dir_monitor.sh
